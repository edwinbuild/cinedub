## Implemented workflow

Import English media → FFmpeg preparation → actual audio/video playback and waveform → batch transcription/diarization → editable revision → Malayalam translation → correction/approval → revision-bound SRT export.

The development branch additionally connects approved dialogue → stock-voice assignment → candidate generation → conservative timing fit → explicit take selection → dialogue-only WAV/MP4 preview. Optional offline English ASR is connected through the same revision workflow with manual speakers, not diarization.

Consented-clone preparation/enrollment, explicit voice selection, consent history/revocation and separate provider-deletion jobs are now connected. Local/reference and recorded-provider paths are tested; real Sarvam cloning is not verified.

Reviewed music/effects and selected takes now render stereo PCM24/MP4/SRT with measured loudness, file manifests and separately accepted export bundles. [Mix verification](retained-background-mix.md) records technical and natural-scene listening gates.

## Local-model measurement — synthetic scene only

Verification on 2026-10-15: 66 backend tests, contract generation checks, strict TypeScript, Ruff, ESLint and the production build pass. The standard four Chrome workflows and three opt-in workflows cover offline ASR, separation-to-recognition and separation-to-reviewed stereo export with actual browser playback. [The maximum-duration separation run](local-separation.md#two-minute-resource-run-on-2026-10-15) records one 120-second synthetic input; it does not certify natural cinema quality or all laptop workloads.

Pinned model: `Systran/faster-whisper-small.en@d1d751a5f8271d482d14ca55d9e2deeebbae577f`, MIT license; faster-whisper 1.2.1, CTranslate2 4.8.3. CPU int8, four threads, one model process, no batching/GPU. Model storage was 464 MiB. The available GPU was independently detected as RTX 3070 Ti Laptop, 8 GiB VRAM; GPU inference was not tested.

An original 14.8-second two-voice eSpeak scene produced 27 expected words, ignoring punctuation, in 4.484 seconds at 623.5 MiB peak process RSS. Estimated word times are retained in the raw artifact but are not forced alignment. No speaker identities or emotion values were inferred.

Reproduce with the optional setup in the README, generate the fixture, prepare it through normal ingest, then run local transcription. `CINEDUB_E2E_TRANSCRIBER=local npm run test:e2e -- tests/e2e/local-asr.spec.ts` independently exercises the actual model through browser/API/worker. The default browser suite intentionally skips that test. Do not extrapolate one clean synthetic clip to cinema speech, accents, overlapping dialogue or music.

## Required live release gate — pending

No Sarvam key was configured during implementation. Never paste one into chat or commit it. Put it in root `.env` and enable Sarvam routing as described in the README.

1. Generate the original spoken fixture using `python3 scripts/make-evaluation-scene.py`.
2. Import it, transcribe with diarization and translate; confirm requests succeed, remote IDs persist, costs are recorded, and the English/Malayalam text appears in the correct lines.
3. Repeat with a licensed natural scene containing one or two speakers and realistic background audio.
4. Listen and correct the transcript, speaker assignments and phrase boundaries; document recognition/diarization failures rather than hiding them.
5. Have a Malayalam-speaking reviewer record meaning accuracy, naturalness, names, omissions/additions and colloquial suitability on a 1–5 scale. Fix meaning-changing errors before accepting the scene.
6. Edit/approve lines, reopen the project and confirm the exported SRT matches saved timings/text. Retranscribe into a candidate and confirm the reviewed revision is intact.
7. Assign Bulbul v3 stock voices, generate and listen to Malayalam candidates, select takes, and render the dialogue-only preview. Record pronunciation, voice naturalness, pacing and timing fit; do not accept clipped speech or meaning-changing edits to force a fit.

Capture scene identifier/license, duration, provider/model, routing/style, timestamp, request IDs, estimated versus dashboard cost, corrections and reviewer notes in this folder. Keep scene audio, credentials and actor reference recordings in ignored local storage.
